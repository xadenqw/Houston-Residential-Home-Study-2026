# Houston Residential Property Analysis

An end-to-end data analytics project analyzing 2,000+ Houston residential property records.

### Tools

* **Python / pandas** — Data cleaning and transformation.
* **R** — Statistical analysis and data visualization.
* **SQL** — Data querying and property categorization.
* **Power BI** — Interactive dashboard and market trend visualization.

### Project Overview

Cleaned and transformed residential property data, analyzed relationships between home characteristics and sale prices, compared Houston ZIP codes, and created an interactive Power BI dashboard to visualize residential market trends.

### Key Skills

Data Cleaning • Statistical Analysis • SQL • Data Visualization • Python • R • Power BI
